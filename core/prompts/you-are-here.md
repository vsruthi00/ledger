# Prompt: you-are-here

Input: ROADMAP, selected shards, recent git changes.
Produce a concise orientation, no fluff:
- One sentence on what the project is and the current focus.
- 3-6 bullets of the state relevant to today's task, drawn only from loaded shards.
- A launch-readiness line: "<status>, <readiness>% ready, ETA <date>".
- The single most useful next action.
Style: no emojis, no em dashes, sentence case prose, DD.Month.YYYY dates.
